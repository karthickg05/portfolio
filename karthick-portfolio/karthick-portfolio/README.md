# Karthick Ganesan — Portfolio

A responsive, animated personal portfolio built with plain HTML, CSS and JavaScript.

## Included
- Premium glassmorphism / gradient visual system
- Responsive mobile navigation
- Dark / light theme with localStorage
- Animated hero section and interactive profile card
- Scroll reveal animations
- Skill category tabs with animated proficiency bars
- Project filtering
- Internship timeline
- Education and certification marquee
- Magnetic buttons and cursor glow
- Back-to-top control
- Mail and LinkedIn contact actions

## Run locally
Open `index.html` in a browser.

For the best local development experience, run any static server, for example:
`python -m http.server 5500`

Then open:
`http://localhost:5500`

## Personalize
- Replace the `KG` avatar inside `index.html` with an image later if you want.
- Add project GitHub/live-demo links to each project card.
- Update skill percentages if you want to avoid presenting them as self-assessed estimates.
- Add a downloadable `resume.pdf` and link it from the hero buttons if desired.
